# POI 飽和偵測專題：方法論與資料來源深入研究報告

## TL;DR
- **核心假設需要重新表述**：「POI 密度存在飽和上界」在文獻上大致站不住腳——城市 scaling laws 顯示商業/創造性活動多為 superlinear（Bettencourt et al. 2007 給出 GDP β=1.15、new patents β=1.27），密度分布為 heavy-tailed，沒有明確上界；但你的直覺在改成「特定業態的過度聚集」與「組成（composition）偏離常態」框架後，是有文獻與實證支持的（便利商店、餐廳研究都發現 inverted-U 存活關係）。
- **autoencoder latent outlier ≠ 商業過飽和**這個弱點是真實的、且無法只靠模型內部解決；務實路線是取得 proxy ground truth（首爾商圈開閉業率、東京/全國商店街空き店舗率、NYC Storefront Registry 空置、Yelp is_open）並用 downstream validation + convergent validity（與 Ripley's K、Geyer saturation model 比較）雙軌驗證。
- **最推薦的 ground truth**：首爾「우리마을가게 상권분석서비스」（含폐업신고율、평균 폐업기간、점포증감률、以폐업신고율與3年生존율為基礎的「과밀지수（過密指數）」，全球最完整的公開商圈資料）；其次 NYC Storefront Registry（直接記錄店面空置）與 Yelp Open Dataset（is_open 標記，最易上手）。

## Key Findings

### 問題 1：商業/設施飽和的既有定義與量化指標

**Index of Retail Saturation (IRS)** — 有正式定義，但只是部分對應你在做的事。
- 精確定義：衡量某商圈對某類零售的「需求 vs 供給」比率，判斷 over-stored / under-stored / saturated。
- 公式：IRS = (H × RE) / RF，其中 H = 商圈家戶數，RE = 每戶對該類商品的年支出，RF = 該類零售的營業樓地板面積（含擬開新店）。由 Dunne, Lusch & Carver 的 *Retailing* 教科書標準化。
- 需要資料：家戶數（人口普查）、家戶消費支出（消費調查）、既有零售樓地板面積。
- 背後機制：需求供給均衡；IRS 越低表示每單位零售面積分到的購買力越少 → 越飽和。
- 是否對應：**部分對應但機制不同**。IRS 是「金額/面積」的經濟供需比，你做的是「POI 點的數量與組成」的空間統計異常。IRS 需要銷售額/樓地板面積資料，是單一業種的 aggregate 指標，無法捕捉「組成異常」。它可作為一個 convergent validity 的外部比較指標，但不是你方法的直接對應。

**Central Place Theory（中心地理論，Christaller / Lösch）** — 是理論假說框架，非飽和指標。
- 核心概念：threshold（維持一個機能存活所需的最低需求人口）與 range（消費者願意移動的最大距離）。當 range > threshold 有利潤空間，市場趨向六邊形嵌套的中地層級。
- 對應性：它解釋「為什麼不同層級的機能有不同的服務範圍與數量」，隱含「同一地點某機能數量有上限（由 threshold/range 決定）」——這一點與你的飽和直覺相關。但 CPT 是均衡的規範性理論，假設均質平原、理性消費者，實證上很少直接用來偵測「過飽和」。它更適合作為你「為什麼組成會有規律」的理論支撐。

**Agglomeration economies vs congestion effects** — 這是最關鍵、也最可能推翻你「密度=壞事」直覺的文獻。
- 集聚經濟（Marshall 三機制：勞動力池、投入品共享、知識外溢）+ 零售的 comparison shopping／餐廳街效應，都指出「同業聚集帶來正外部性」，高密度不必然是過飽和，反而常是效率表現。
- 擁擠/競爭效應：超過某門檻後負外部性主導。多篇實證發現這是 **inverted-U（倒U形）** 關係——這正是支持你假設「過猶不及」的證據（見問題 5）。

**你可能不知道但更對應的概念**：
- **Reilly's law of retail gravitation / Huff model**：重力模型，估計消費者到各店的機率 P_ij = (A_j^α / D_ij^β) / Σ(A_k^α / D_ik^β)。Huff model 廣泛用於「grocery 這類最飽和市場」的 benchmarking 與 site selection，可用交易資料驗證（arXiv 1902.03488）。這些是「市場份額分配」模型，對應「新增一店會稀釋既有店客源」的飽和機制，比 IRS 更接近你的問題。
- **Location Quotient (LQ)**：某業種在本地佔比 / 全國佔比，衡量產業專業化/集中，可作為「組成異常」的簡單 baseline。
- **Herfindahl-Hirschman Index (HHI)**：業態組成的集中度。
- **Entropy / diversity index（Shannon、Simpson、Margalef richness、Hill numbers）**：已被廣泛用於 POI 組成多樣性與 urban functional zone 研究。Shannon entropy 用來量測 land use / POI mix；Margalef richness index R = (S−1)/ln(n)（S=POI 類數、n=POI 數）。Simpson 對應 Hill number q=2、Shannon 對應 q=1。這正是量化「組成」的成熟工具。
- **Urban functional zone 研究**：以 POI 密度、diversity、空間分布辨識功能區。文獻中很少有人正式定義 POI「飽和」，多半定義「功能純度/混合度」——這暗示學界目前把重點放在「組成」而非「密度上界」，與我對你假設的建議方向一致。
- **Carrying capacity**：源自生態學的環境承載力概念，在都市研究中多用於觀光承載、環境承載，較少嚴格量化到「零售 POI 承載上限」，屬於隱喻式借用。

### 問題 2：空間點過程統計——聚集 vs 規則，以及「飽和」對應概念

**判斷聚集 vs 規則的工具**：
- **Ripley's K function** K(r)：以任一點為中心，半徑 r 內的期望點數 / 強度。CSR（完全隨機 Poisson）下 K(r)=πr²。觀測 K(r) > πr² → 聚集；< πr² → 規則/互斥。常用變換 L(r)=√(K(r)/π)，CSR 下 L(r)=r。spatstat 函數：`Kest()`、`Lest()`，顯著性用 `envelope()` 做 Monte Carlo。
- **Pair correlation function g(r)**：K 的微分形式，g(r)=K'(r)/(2πr)。g(r)>1 聚集、<1 抑制、=1 隨機。比 K 更能分辨特定尺度。spatstat：`pcf()`。
- **Hard-core process**：點之間有最小距離（硬核半徑），是規則性的極端。
- **Gibbs / Strauss process**：以交互作用參數 γ 建模，γ<1 抑制；但 γ>1 的 Strauss 不可積，故 Strauss 只能建模抑制。

**「飽和」在點過程語言中的對應**：
- **Geyer saturation process（Geyer 1999）**：這名字就是 saturation，很可能正是你要的概念。它是 Strauss process 的修正：每個點來自與所有鄰點 pairwise 交互作用的貢獻，被「截斷」到一個最大值 s（saturation threshold）。機率密度中每個點 x_i 貢獻因子 γ^min(s, t(x_i,X))，其中 t(x_i,X) 是 x_i 在半徑 r 內的近鄰數。關鍵：一旦近鄰數超過 s，再增加鄰點就不再改變該點的貢獻——這在數學上就是「local 到達飽和後，額外的點不再有邊際效應」。這與你「塞入更多 POI 造成過飽和」的直覺在形式上高度呼應。而且因為有截斷，γ>1（聚集）也變得可積，能同時建模聚集與抑制。spatstat：`ppm(X, ~1, Geyer(r, sat))`。
- **Area-interaction process (Baddeley–van Lieshout)**：以點的緩衝區聯集面積建模，可同時表達聚集與規則。spatstat：`AreaInter()`。
- **Matérn hard-core process**：透過刪除過近的點產生最小間距，天然有「密度上限」（給定硬核半徑，單位面積最多容納的點數有上界）——這是「規則性造成的密度上限」，概念上接近飽和。
- **RSA (random sequential adsorption) / jamming limit / packing density**：**這是「物理飽和上限」最直接的類比**。隨機依序放置不重疊的圓盤，到某點再也放不下任何一個 → jamming（塞滿）。2D 等大圓盤的 jamming coverage θ(∞) ≈ 0.547（最精確估計 0.547068869 ± 0.000000057，Kubala et al. 2022；Zhang & Torquato 2013 為 0.5470735；1D 車位問題的 Rényi parking constant ≈ 0.7476）。這給你一個明確的「幾何飽和」定義：若把每個 POI 視為佔據一塊排他面積，理論上覆蓋率有上限。**但務必注意**：真實 POI 不是等大硬圓盤、可以垂直疊加（同一棟樓多店）、排他半徑不明確，所以 0.547 只能當概念類比與理論上界，不能直接套用為經驗閾值。

**作為 baseline 與 autoencoder 比較的可操作步驟**：
1. 把研究區的 POI 當作 marked point pattern（mark = 業態類別），在 R 用 `spatstat` 建立 `ppp` 物件。
2. 整體聚集/規則：`Kest()` / `pcf()` + `envelope()`（CSR 檢定）。因為城市 POI 強度非均質，改用 **inhomogeneous K**：`Kinhom()`、`pcfinhom()`（先用 `density.ppp()` 估 λ(x)）。
3. 飽和建模：`ppm(X, ~polynom(x,y,2), Geyer(r=..., sat=...))`，比較不同 sat 的 AIC；擬合後可 `simulate()` 看能否重現觀測聚集程度。
4. 局部異常：`localK()` / `localL()`，或 LISA（Local Moran's I，用 `spdep::localmoran()` 在網格化強度上）找局部異常聚集。
5. Marked / multitype 方法（因 POI 有類別）：
   - `Kcross(X, i, j)`：i 類點周圍 j 類點的期望數，判斷跨業態吸引/排斥。
   - `pcfcross()`：跨類 pair correlation（=1 表示兩類獨立）。
   - `markcorr()`：mark correlation function。
   - `markconnect()`：mark connection function。
   - **隨機標記假設檢定**：用 `envelope(X, Kcross, simulate=expression(rlabel(X)))`，透過打亂標籤檢定「業態標籤是否隨機分布」——這直接對應「某地業態組成是否異常」。
- Python 對應：`pointpats`（Ripley's K/L、G、F）、`astropy.stats` 的 two-point correlation、`PySAL/esda`（Moran's I、LISA）。Gibbs/Geyer 類擬合 Python 生態較弱，建議這部分用 R spatstat。

### 問題 3（最重要）：ground truth 資料集

以下按「作為過飽和 proxy 的可用性」分級整理。

#### 🥇 第一梯隊（直接、可下載、免費、含開閉業或空置）

**首爾「서울시 우리마을가게 상권분석서비스」（golmok.seoul.go.kr）+ 서울 열린데이터광장（data.seoul.go.kr）**
- 這是全球最完整的公開商圈分析資料之一。官方明確以「過密化（과밀화）골목상권」為問題意識。其核心指標「과밀지수（過密指數）」定義為：以行政區（구·동）別的**폐업신고율（歇業申報率）與 3年生존율為基礎，衡量需求對比供給的飽和程度（수요 대비 공급의 포화정도）**，並以 5 色紅綠燈標示新進入風險。生活密接業種共 100 類（外食 10 + 服務 47 + 小賣 43）。「자치구별 창업위험지표」危險度分級：주의(≤40)/의심(40–51)/위험/고위험。
- 具體資料集（data.seoul.go.kr）：
  - 「자치구별 창업위험지표」：分季提供신규창업위험도、**폐업신고율**、3年間開業對比歇業申報率、**평균 폐업기간（平均歇業期間）**、**점포증감률（店鋪增減率）**。
  - 「점포-행정동」「점포-상권」：行政洞/商圈別점포수 + 開/廢業 + 프랜차이즈。
  - 「추정매출」：估計營業額（信用卡資料，2021 年起）。
  - 空間單位：상권（商圈）/ 행정동 / 2024 年起改為標準單位區域。免費、免登入、CSV/API。
- **這是最理想的 proxy ground truth**：폐업신고율高、평균 폐업기간短、점포증감률負、過密指數高 → 直接對應「過飽和導致汰換」。

**日本 中小企業庁「商店街実態調査」（空き店舗率 = 官方空置率統計）**
- 直接就是官方「空置率」統計。全國調查，令和3年度平均空き店舗率 13.59%（平成30年度 13.77%）。**空置率 10% 以上的商店街佔全體 43.3%，較前回調查（41.3%）增加 2.0 個百分點。退店・廃業理由中「同業種との競合（同業競爭）」佔 22.7%**——這條理由本身就是「過飽和」的直接佐證。
- 昭和45年開始，約每3年一次；令和6年起改由全国商店街振興組合連合会執行。令和3年度向 12,210 件商店街發送、有效回答 5,105 件。
- URL：chusho.meti.go.jp/shogyo/shogyo/shotengai_chousa.html（含概要版/詳細版/都道府県別データ PDF+資料編）。免費。
- 限制：以「商店街」為單位的問卷調查，非點位級、非全普查；空間解析度粗（商店街層級）。
- **東京都版**：東京都産業労働局「東京都商店街実態調査報告書」（直近令和4年度），更細緻的東京商店街空置與業種構成。

**NYC Storefront Registry / Storefronts Reported Vacant or Not（NYC Open Data）**
- 依 Local Law 157 (2019，2022 修正) 要求業主每年（及每半年補充）申報店面是否空置，**直接記錄 storefront vacancy**。
- NYC Open Data dataset「Storefronts Reported Vacant or Not」(id 92iy-9c3n)，免費、CSV/API。
- 涵蓋：全市 ground/second floor 商業店面，逐筆 BBL 級（比 census tract 更細）。時間 2019 起逐年。2021/12/31 共 **6,631 空置店面、空置率 10.4%；曼哈頓最高 13.77%，其次布魯克林 9.82%、史泰登島 8.94%**。最新可補：NYC Comptroller「Who's Minding the Storefronts?」(2026/6/4) 報告全市空置率 **11.0%（2026/4/15），約 15,700 家空置，Financial District–Battery Park City 最高 21.1%**。
- 限制：自我申報（self-reported），有漏報與資料品質問題。

**Yelp Open Dataset（is_open 欄位 = 最易上手的存活標記）**
- business.json 含 `is_open`（0=closed, 1=open）、categories、lat/long、review_count、stars。官方數字：**6,990,280 則評論、150,346 家商家、200,100 張照片，涵蓋 4 國 11 個都會區**（含 Montreal, Calgary, Toronto, Pittsburgh, Charlotte, Urbana-Champaign, Phoenix, Las Vegas, Madison, Cleveland 等；不含東京）。
- 直接下載（yelp.com/dataset）或 Kaggle，JSON，免費（限學術/教育用途，須遵守 Yelp Dataset ToS）。
- **最容易取得、可立即當弱標籤**：is_open 是很直接的存活標記；缺點是快照式（非長期追蹤開閉時點）、僅 Yelp 收錄的商家、城市不含東京。

#### 🥈 第二梯隊（日本官方統計，密度/組成，開閉業推導）

**経済センサス‐活動調査（e-Stat）**
- 全事業所普查，5年一次（H24, H28, R3）。含事業所数、従業者数、年間商品販売額、業種別（產業細分類）。
- **町丁・大字別結果**確實存在（R3 已公開「事業所数、従業者数（町丁・大字別結果）」，141 件），另有 500m/1km 地域メッシュ統計——這給你町丁目/網格級的密度與組成。
- URL：e-stat.go.jp（統計 id 見活動調查頁）。免費、CSV/Excel/API。
- 「事業所の開設時期」欄位：可粗略推導事業所存續期間分布。
- 限制：5年一次、非逐店追蹤；年間商品販売額在 R3 有部分業種以推估值提供。

**商業統計調査（Census of Commerce）**：已於 2019 後整併進経済センサス，不再獨立實施；歷史資料仍在 e-Stat。

**jSTAT MAP（地図で見る統計）**：e-Stat 附屬 GIS 工具，可做小地域（町丁目）統計與簡易商圈分析（設定半徑/步行圈，套疊人口與事業所），免費、免安裝。適合快速商圈盤點。

**RESAS / V-RESAS（地域経済分析システム）**
- 整合経済センサス等，可視化事業所数增減率（以中央值分區）。含產業結構、人流。2025/3 起改版新系統。
- 限制：主要為可視化與縣市/市區町村級，細粒度原始資料下載有限；開閉業率非其強項（用 e-Stat 或民間資料補）。

**国土数値情報ダウンロードサービス（MLIT, nlftp.mlit.go.jp）**
- 免費 GIS：公共施設、都市計画、地価公示、土地利用メッシュ等點/面資料。適合作為 POI 底圖與控制變數（地價、交通），但商業 POI 覆蓋不如商用地圖或 OSM 完整。

**地価公示 / 都道府県地価調査 / 路線価**：作為租金/地價 proxy（過飽和常伴隨高租金壓力）。地価公示與都道府県地価調査在国土数値情報與 e-Stat 可下載；路線価在国税庁。賃料 proxy 另有三鬼商事オフィスマーケットデータ、アットホーム / LIFULL HOME'S 店舗賃料指數（部分免費、部分付費）。

**法人番号公表サイト（国税庁）**：全法人設立/登記變更/清算，可推導開業/廢業趨勢，免費 API。限制：法人單位非事業所（店面）單位，餐飲小店多為個人事業主不一定有法人番号，涵蓋不完整。

**民間付費（涵蓋最全的開閉業/倒産）**：帝国データバンク (TDB)、東京商工リサーチ (TSR) 的倒産・休廃業データ；食べログ/ぐるなび 的店舗開閉（爬蟲面臨 ToS 限制與反爬，法律/倫理風險，不建議作為主要來源）。

#### 🥉 其他國家/城市（比較或替代）

- **美國 County Business Patterns (CBP) / ZIP Code Business Patterns (ZBP)**：郡/ZIP 級事業所計數，按 NAICS，1986（ZBP 1994）起，最新為 2023 CBP（2025/6/26 發布），免費 CSV/API（census.gov/programs-surveys/cbp/data/datasets.html）。注意：只是「點時間計數」非開閉業。

- **Longitudinal Business Database (LBD)**：全美事業所普查微觀資料含精確 birth/death 年，**限 FSRDC，須經 Standard Application Process Portal (sap.nsf.gov) 申請核准、在安全機房使用**；另有免費合成版 SynLBD。
- **Statistics of U.S. Businesses (SUSB)**：另有「Employment Change」含事業所 births/deaths，郡/MSA 級，1997 起，免費（census.gov/programs-surveys/susb/data/datasets.html）。
- **NETS (National Establishment Time-Series)**：Walls & Associates 販售（源自 Dun & Bradstreet），事業所級逐年 births/deaths/存活，含街道/經緯度，**商業付費**（無公開定價，樣本數計價；部分大學校內免費）。
- **英國 Local Data Company (LDC，現屬 Green Street)**：實地踏查的零售/休閒空置率，**商業訂閱**；headline 空置率在新聞稿免費（近期 GB 全國空置率約在 13–14% 區間，Q4 2023 直接確認為 14.0%）。學術可透過 GeoDS 取得 Local Authority District 級 safeguarded 衍生資料。
- **英國 UK Business Counts (Nomis, nomisweb.co.uk)**：源自 IDBR，enterprises (`idbrent`)/local units (`idbrlu`) 計數，5-digit SIC，可到 MSOA 級，免費。開閉業/存活請改用 ONS「Business Demography」。

- **新加坡/香港**：政府開放資料平台有商業登記與規劃資料（覆蓋與細粒度不如首爾）。
- **台灣**：財政部財政資訊中心「全國營業(稅籍)登記資料集」（data.gov.tw dataset 9400，含營業登記家數、行業、地址，可到村里層級，免費 API）；「財政統計資料庫」營利事業家數及銷售額；經濟部商業司公司登記；內政部實價登錄（租金/地價 proxy）。營業稅籍的設立/註銷可推導開閉業，是台灣最接近首爾資料的來源。

**最容易取得且最能當過飽和 proxy 的排序**：(1) 首爾 우리마을가게（直接有폐업신고율/평균 폐업기간/과밀지수，最理想）；(2) Yelp is_open（最易上手，但非東京）；(3) NYC Storefront Registry（直接空置，BBL 級）；(4) 東京/全國商店街空き店舗率（官方空置率，但商店街級較粗）；(5) 台灣營業稅籍（村里級開閉業推導）。

### 問題 4：無標準答案時的替代驗證方式（具體案例）

- **Synthetic anomaly injection / controlled perturbation**：在已知「正常」的 POI 組成上，人工注入異常（如在住宅網格硬塞 N 家同業酒吧、複製貼上某業態）再看模型能否偵測。文獻做法見「Enhancing Anomaly Detection via Generating Diversified and Hard-to-distinguish Synthetic Anomalies」(CIKM 2024) 用 conditional perturbators 生成合成異常；「Bridging Unsupervised and Semi-Supervised Anomaly Detection」(arXiv 2506.13955, 2025) 明確警告：合成異常來自 uniform 分布，「good performance on synthetic anomalies does not necessitate good performance on unknown anomalies」——注入實驗只能證明「有能力偵測某類人造偏差」，不能證明偵測到真實過飽和。務必報告這個限制。
- **Proxy label / weak / distant supervision**：用問題 3 的 proxy（is_open、폐업신고율、空置率）當弱標籤，即使有雜訊也能算 AUC/AUPR。
- **Face validity / expert elicitation + inter-rater reliability**：找都市計畫/在地商業專家對被標為異常的地點盲評，算 Cohen's κ / Krippendorff's α。
- **Case study 質性三角驗證**：對少數高分異常點做深度個案（街景、營登、新聞），qualitative triangulation。
- **Downstream task validation**：用異常分數去預測有標籤的下游變數（房價/地價、人流、店家存活率、空置率）。若異常分數能顯著預測未來開閉業，才是對「過飽和」有意義的間接證據。
- **Convergent validity**：異常分數與既有指標（Ripley's K/L、Geyer 擬合殘差、Moran's I、IRS、entropy、HHI）的相關性；一致代表捕捉到相似結構。
- **Stability / robustness**：不同隨機種子、latent 維度、超參數、時間切片下異常排名的穩定性（如 rank correlation、Jaccard@k）。
- **統計顯著性 / null model**：對 latent 距離或 reconstruction error 做 permutation test；與 CSR 或 heterogeneous Poisson null（`rpoispp(lambda)`）比較；用 `envelope()` 建立信賴帶。這是把「跟訓練分布不像」升級為「顯著偏離空間虛無模型」的關鍵。
- **前後對照（時間序列）**：今天被標為異常的地方，未來 1–3 年是否真的出現較高店家汰換/空置上升。這是最能逼近因果、也最能支持你假設的驗證，需要 panel 資料（首爾/台灣營業稅籍/NYC registry 都可做）。
- **無監督模型驗證本身的方法**：見「Towards Unsupervised Validation of Anomaly-Detection Models」(Idan, arXiv 2410.14579) 提供無標籤下的 model selection / evaluation 範式。urban 軌跡異常的無監督 benchmark 見 R-U-MAAD (arXiv 2209.01838)，示範「訓練/驗證無標籤、僅測試集有標籤」的設計。

### 問題 5：核心假設「POI 密度飽和」站不站得住腳——誠實評估

**直說：以「aggregate 密度存在飽和上界」表述，文獻上大致站不住腳。**

- **城市 scaling laws（Bettencourt, Lobo, Helbing, Kühnert & West 2007, "Growth, innovation, scaling, and the pace of life in cities", PNAS 104:7301–7306）**：Table 1 給出具體指數——多數社經量呈 **superlinear**：GDP β=1.15、total wages β=1.12、new patents β=1.27、R&D employment β=1.26；基礎設施呈 **sublinear**：gasoline stations β=0.77、road surface β=0.83、length of electrical cables β=0.87。商業/創造性活動偏 superlinear，意味著「城市越大、每人擁有的商業活動更多」，**沒有出現飽和平台**。這是對「密度有明確上界」最強的反證。
- **Heavy-tailed / power-law 分布**：POI 與商業密度多呈重尾分布，Zipf's law for cities 亦然，暗示沒有自然的上界截斷。
- **集聚經濟正外部性**：Marshall 三機制、comparison shopping、餐廳街效應都說明「高密度常是效率而非病態」。「Location and Agglomeration: The Distribution of Retail and Food Businesses in Dense Urban Environments」等指出競爭性群聚普遍存在且有正效益。
- **IRS 的預測效力有限**：IRS/重力模型（Reilly、Huff）是實務工具，但 IRS 是靜態供需比、對「組成」與空間結構不敏感；重力模型文獻（Springer「Retail Gravitational Models: A Review」）也列出諸多理論與操作限制。沒有強證據顯示單純 aggregate 密度能穩健預測倒閉率。

**但你的直覺在下列改寫後是有實證支持的**：

- **inverted-U（倒U形）存活/績效關係確實存在**：
  - 便利商店：Seong, Lim & Choi (2022), *Environment and Planning B: Urban Analytics and City Science*, 49(3):834–846, DOI:10.1177/23998083211021870，發現群聚帶來營收，但原文「This benefit, however, disappears when the competition increases beyond a certain threshold.」——明確的門檻/過飽和證據。
  - 餐廳：Yelp eWOM 研究發現 density / product / temporal agglomeration 對 eWOM 呈 inverted-U。
  - 零售群聚存活：「When does retail clustering support store survival?」(*Journal of Marketing Theory and Practice* 2026, LA County 1990–2020, Cox proportional hazards) 發現群聚的存活效益「highly contingent」，對大型連鎖/老店/低所得區可能反轉為負。
  - 首爾：「Effect of Agglomeration Externalities... on Commercial Business Continuity in Seoul」發現 related diversity 增加關店機率、unrelated diversity 降低關店機率——**證明「組成」比「總密度」更關鍵**。
- **飽和是 category-specific，不是 aggregate**：同一條街第5家便利商店 vs 第5家不同業態的店，效果天差地別。文獻普遍支持「same-type 競爭」與「cross-type 互補」的區分（呼應問題2的 Kcross/隨機標記檢定）。
- **「組成異常」框架有立足點**：urban functional zone 文獻顯示 POI 組成（density + diversity + spatial pattern）在不同功能區有穩定規律（商業區密度與多樣性最高、工業區稀疏同質）。偏離該功能區的組成常態，確實是有意義的訊號——這比「密度過飽和」更站得住腳。

## Details 與整體方法論建議

**核心問題重新表述（三選一或組合）**：
1. 從「密度飽和」改為「**特定業態的局部過度聚集**」：用 marked point process（Kcross、隨機標記檢定、Geyer saturation 對單一業態擬合），偵測「same-type over-concentration」。這有便利商店/餐廳 inverted-U 的實證支撐。
2. 從「密度」改為「**組成異常**」：autoencoder 學習「給定情境（人口、地價、功能區）下的正常業態組成向量」，latent outlier = 組成偏離常態。這與 functional zone 文獻一致，且避開「密度無上界」的理論陷阱。
3. 保留飽和語言，但錨定在**可操作的物理/統計定義**：Geyer saturation threshold（統計飽和）或 RSA jamming（幾何飽和上界），並明確聲明這是「與虛無模型的偏離」而非「商業過飽和」。

**為什麼 autoencoder latent outlier 需要外部驗證**：latent outlier 只證明「輸入 ≠ 訓練分布」。要讓它有「商業過飽和」的意義，必須（a）在 downstream 上顯示異常分數能預測未來開閉業/空置（問題3 proxy），且（b）與空間統計 baseline（Geyer、Kcross、entropy）convergent。二者缺一，reviewer 都會質疑效度。

**最務實的驗證路徑（建議執行順序）**：
1. 選 **首爾**（資料最全）或 **東京**（你偏好，用経済センサス町丁目 + 商店街空き店舗率 + 可選台灣營業稅籍作對照）。
2. 建 POI marked point pattern，先跑 spatstat baseline：`Kinhom/pcfinhom`、`Kcross` + `rlabel` 隨機標記檢定、`ppm(...Geyer(r,sat))`。這一步不需要 autoencoder 就能產出「哪裡 same-type 過度聚集/組成異常」的可解釋結果，且直接可發表。
3. 訓練 autoencoder（輸入 = 網格/商圈的 POI 組成向量 + 情境變數），取 latent outlier / reconstruction error。
4. **雙軌驗證**：(a) convergent validity（autoencoder 分數 vs Geyer 殘差/Kcross/entropy 的相關）；(b) downstream（用 proxy label 폐업신고율/空置率/is_open 算 AUC，並做前後對照 panel）。
5. 加 synthetic injection 與 permutation/null model 檢定佐證，但如實報告其限制。

- **建立 baseline 再上深度模型**：先做 spatstat 空間統計，確保有可解釋、可比較的參照；autoencoder 的價值在於同時處理高維組成 + 情境，需用 convergent + downstream 雙軌證明它比 baseline 多帶來什麼。

- **會改變建議的訊號**：若 downstream 預測不顯著或與 baseline 無異 → latent outlier 捕捉的多半是資料稀疏/邊界效應而非過飽和，應退回純空間統計框架或改做組成分類。若拿不到任何 proxy label → 以 synthetic injection + null model + 專家盲評 + 個案三角作為降級但誠實的驗證組合，並在標題/摘要避免宣稱偵測「商業過飽和」。

## Caveats

- **有實證支持 vs 只是理論假說的區分**：*有實證支持*——urban scaling exponents（Bettencourt 2007）、便利商店/餐廳 inverted-U（Seong 2022、Yelp eWOM）、首爾 diversity 與關店率、商店街「同業競合」佔退店理由 22.7%、各城市空置率數字、Geyer/RSA 的數學性質；*只是理論假說/隱喻*——「POI 密度存在單一飽和上界」、carrying capacity 應用於零售、RSA 0.547 直接當 POI 經驗閾值、CPT 對真實城市的均衡預測。
- **Yelp 的 is_open 是快照**，不含關店時點，只能做橫斷面弱標籤；且不含東京。
- **商店街空き店舗率是問卷、商店街級**（非點位、非普查），解析度粗；令和3年度回收 5,105/12,210 件。
- **NYC Storefront Registry 為自我申報**，有漏報。
- **経済センサス 5 年一次**，年間商品販売額部分為推估；不適合做細時間解析度的前後對照。
- **RSA 的 0.547 jamming coverage 是等大硬圓盤的理論值**，真實 POI 可垂直疊加、排他半徑不明，只能當概念類比，不能直接當經驗閾值。
- **首爾資料為韓文、業種分類（생활밀접업종 100類）與國稅廳分類不同**，跨城市比較需對照分類。
- **UK LDC 最新空置率（約13–14%）** Q4 2023 直接確認 14.0%，更新期數建議向 LDC/Green Street 或 BRC-LDC Vacancy Monitor 核實。
- **inverted-U 存活文獻多為特定業態/城市**（便利商店、餐廳、首爾/LA/Phoenix），外推到全業態需謹慎。
- 台灣營業稅籍「家數」以稅籍為單位，一址多稅籍或歇業未註銷會造成誤差。
